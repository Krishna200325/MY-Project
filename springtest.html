Spring Core Coding Assessment

Complete these practical coding tasks as you would in a technical screening. Write code, run it in your Java project, and mark each verified task.

Note: This standalone HTML page cannot compile Java. The marks below count tasks you entered and marked tested; verify correctness in your IDE.

Task 1 — Create a service component

Create an EmailService Spring bean with a method that sends a message. Use an appropriate component annotation.

Task 2 — Use constructor injection

Create an OrderService that requires EmailService. Inject the dependency through its constructor; do not instantiate it with new inside OrderService.

Task 3 — Configure component scanning

Write a Java configuration class that enables component scanning for com.example.service. Show how you would obtain a bean from the application context.

Task 4 — Choose and configure bean scope

A stateless service should be shared by the application. Declare the appropriate Spring scope and briefly demonstrate the bean definition.

Task 5 — Add a lifecycle callback

Add initialization and cleanup callbacks to a Spring-managed bean. Use the relevant Jakarta annotations and ensure the bean is discovered by Spring.
