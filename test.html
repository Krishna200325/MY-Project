Hibernate Coding Assessment

Complete these practical tasks as you would in a technical screening. Write code, run it in your Java project, and mark each verified task.

Note: This standalone HTML page cannot compile Java. The marks below count tasks you entered and marked tested; verify correctness in your IDE.

Task 1 — Create a Customer entity

Map a Customer class to a customers table. Add a generated Long ID, a required name, and a protected no-argument constructor.

Task 2 — Build a repository

Create a Spring Data JPA repository for Customer with a method to find a customer by email.

Task 3 — Add a transactional service

Implement a service method that saves a customer using constructor-injected repository dependency and a transaction boundary.

Task 4 — Map an order relationship

Map Order to Customer as many-to-one. Choose a suitable fetch strategy and avoid exposing an unnecessary full entity graph in an API response.

Task 5 — Fix an N+1 query

Orders are loaded in a list and each order triggers another query for its customer. Show a repository query or entity graph that fetches the needed customers efficiently.
